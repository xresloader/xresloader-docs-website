Capabilities

Explore all capabilities↗
01

Batch conversion across platforms

A Java engine, native Rust CLI and Tauri GUI work together on Windows, macOS and Linux. Designers and build pipelines use the same manifests.

Read the guide and examples↗
02

Multiple output formats

Export protobuf, MsgPack, Lua, JavaScript, JSON, XML and Unreal Engine DataTable JSON / CSV for clients and servers.

Read the guide and examples↗
03

Nested messages and field types

Use proto2 / proto3, nested messages, repeated fields, oneof, map and in-cell Plain structures to describe your data model.

Read the guide and examples↗
04

Export enums and descriptors

Export schema enums, constants and descriptors as Lua / JavaScript code or JSON / XML data, with custom options for reflection.

Read the guide and examples↗
05

Aliases and validation

Field and enum aliases, macros, ranges, cross-table references and composed validators catch input errors during conversion.

Read the guide and examples↗
06

Field mapping and merged tables

Merge Excel sources, map field names with regular expressions, select ranges and transpose data. Schema options control export behavior.

Read the guide and examples↗
07

Output controls

Choose cached or explicitly evaluated formulas, trim or retain empty data, set data versions, and filter outputs by format, directory and tags.

Read the guide and examples↗
08

Data loaders and indexes

Integrate with C++, C#, Go, upb, pbc or lua-protobuf. Lua supports global / require / module; JavaScript supports global / Node.js / AMD.

Read the guide and examples↗
09

Unreal Engine and project extensions

Export UE DataTables and generate loaders. Connect project tools through GUI events, custom buttons and Node.js scripts; inspect binary data with dump-bin.

Read the guide and examples↗
